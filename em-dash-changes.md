## Replacement rules used

- **Comma**: the dash set off an aside, contrast ("…, not X") or trailing phrase.
- **Colon**: what follows explains, lists or labels what came before (also used in image alt text, captions, step labels and code comments, e.g. "L1: Measure Category Overview").
- **Semicolon**: the dash joined two complete sentences.
- **Period**: a new sentence reads better (next word capitalized).
- **Parentheses**: a pair of dashes wrapped a list or example inside a sentence.
- **Pipe ( | )**: page `<title>` separators, matching the existing "|" already used in the homepage title.
- **En dash (–)**: only the decorative list-bullet marker in the CSS of Crisis Forecasting Planning, kept to preserve the design (swap to • if you want no dashes at all).
